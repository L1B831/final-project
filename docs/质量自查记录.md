# 扬帆手账 · 质量自查记录

按指南质量清单完成四项自查。每项含检查方法、预期结果与实测记录。

## 1. 断网提示

- **检查方法**：DevTools（F12）→ Network 面板 → Throttling 选 Offline → 刷新页面
- **预期结果**：页面顶部出现明确警告条"网络连接失败……请检查网络后刷新重试"，而不是白屏或脚本报错无提示
- **实现方式**：库脚本之后、`app.js` 之前有一段原生 JS 兜底，检测到 jQuery / ECharts / Chart.js 任一未加载即在 `#status` 警告条显示提示
- **实测记录**：□ 已实测并截图（截图：断网-offline.png）

## 2. 空数据

- **检查方法**：支出看板区"数据源"下拉切换为"空数据（empty.json）"
- **预期结果**：警告条显示"暂无数据"，卡片与图表清空，无 Console 报错；切回正常数据后恢复
- **实测记录**：□ 已实测并截图（截图：空数据-empty.png）

## 3. 三档宽度

| 档位 | 检查要点 | 预期结果 |
|------|---------|---------|
| 手机 375px | 导航折叠为汉堡菜单；卡片单列；明细表在 `table-responsive` 内横向滚动、页面无横向滚动条 | 正常 |
| 平板 768px | 导航展开；卡片两列 | 正常 |
| 桌面 1200px+ | 卡片三列；双图表完整显示 | 正常 |

- **实测记录**：□ 375px □ 768px □ 1200px（截图：宽度-375.png / 宽度-768.png / 宽度-1200.png）

## 4. Console

- **检查方法**：正常浏览全流程（加载 → 筛选 → 切换空数据 → 切回 → 进入三维页返回）后查看 Console
- **预期结果**：无报错、无警告
- **实测记录**：□ 已实测并截图（截图：console-clean.png）
