## 三、风险清单（具体风险 + 影响 + 应对）

| 风险 | 影响 | 应对 |
|------|------|------|
| 双击 index.html 用 file:// 打开，fetch 加载本地 JSON 被浏览器拦截，看板全空白 | 演示时页面无数据，被判"功能未完成" | README 首节即写明必须用本地服务器（`python -m http.server`），演示前固定用 http://localhost:8000 访问 |
| 断网或 CDN 不稳时 jQuery/ECharts/Chart.js 加载失败，脚本抛 `$ is not defined`，页面无任何提示 | "断网提示"自查项不过关 | 在库脚本之后、app.js 之前加一段原生 JS 兜底：检测到任一库缺失即在页面顶部警告条给出明确提示 |
| ECharts 与 Chart.js 双图表库共存，容器高度塌陷或重复初始化导致图表不显示、切换数据源时报错 | 图表模块失效，Console 报错 | 两个图表容器分别固定高度；Chart.js 每次渲染前 `destroy()` 防重复初始化；监听 resize 让 ECharts 自适应 |
| 手机宽度下明细表格列多溢出，产生横向滚动条 | "三档宽度"自查项不过关 | 表格外层套 Bootstrap `table-responsive`；金额列右对齐压缩列宽；375px 实测确认 |
